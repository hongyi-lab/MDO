官方预训练 ATsurf_L（14,517,280 参数）使用 450 个训练工况、144 个训练几何，按预先固定的 MDO 损失全参数适配 5 epochs（2250 次更新），Adam、学习率 1e-5、batch 1、FP32、seed 7。使用固定末轮 checkpoint，不依开发集挑选轮次。48 个开发几何、350 工况用于以下评价；以几何等权、每个几何内工况等权汇总。

1 drag count = 1e-4。CL/CD 汇总以发布数据的表面重积分参考系数为基准，不是原求解器全表面的力系数。训练则使用同一 CFD 表面场重新积分的目标；逐例评价另存两种参考值的积分一致性误差，以及相对于现场重新积分值的误差。CL MAE 降低约 59.2%，CD MAE 降低约 44.6%，展向载荷 RMSE 降低约 31.4%。一个 seed、固定 5 epochs 的开发试验尚不能说明跨随机种子显著性、正式测试精度或置信放行率。

改善并非覆盖每个样本：CL、CD、展向载荷误差分别有 76、69、100 个工况变大（各自共 350）。几何内最坏误差的 P95，CL 从 0.05090 降至 0.03271，CD 从 38.86 降至 26.94 drag counts。平均指标和尾部必须一起展示，不能只挑好看的案例。

## 耗时含义

RTX A6000，Torch 2.11.0/CUDA 12.8，FP32、TF32 关闭、CPU 后处理 4 线程。每次预测计时包含输入准备、同步模型计算、表面场后处理和气动力积分；不包含模型加载、读盘、输出存盘。350 个开发样本上统计中位数，不能视为一次请求的冷启动耗时。适配后模型结构未变，约 0.2 ms 的中位差异不足以声称适配提高了推理速度。

本轮训练 fit 计时约 166.7 秒，整个训练入口约 171.9 秒，不含环境安装、数据和预训练权重下载。这也不是基础模型的预训练成本。

## 独立原生 CFD 尝试：未合格

`alpha6p71_mach0p8_L81_v2`：352.8 万网格单元，8 MPI ranks，每 rank 1 线程。生成网格成功；ADflow 达到 3000 次内部迭代预算（末行为 3013），共有 164 次主迭代。相对残差为 7.187e-5，未达到 1e-10，退出状态为 `not_converged`。未发生十分钟超时终止。

网格生成 204.6 秒，求解 2566.3 秒，总体约 2792.8 秒。**这是失败尝试的成本，不能将它除以 32 ms 报告等精度加速倍数。** 未收敛的 CL/CD 也不能当作参考真值。

原生到模型的坐标/迎角变换、后缘闭合和表面采样尚需按 [坐标审计](NATIVE_FM_FRAME_AUDIT.md) 对齐；当前原生 6.71 度实际上对应模型约 13.43 度。上述开发集直接使用已处理的发布几何，不走这个原生转换路径，不能把两种验证混在一起。

后续原生 AoA=2 度、Mach=0.8 的 `alpha2p0_mach0p8_L81_v1` 已于 07:48:50 UTC 退出。保持 1e-10、3000 次内部迭代预算和 8 MPI ranks，复用原有经校验的 81 层网格。从完整日志恢复的诊断显示：148 次主迭代、末行累计内部迭代3005、末行总残差26534.36；求解2508.747秒，初始化18.746秒。没有获得合格收敛结果。
