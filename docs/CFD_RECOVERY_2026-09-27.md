## 已知事实

运行环境是固定摘要的 MDOLab 官方镜像中的真实 ADflow，非自写近似 CFD。ADflow 的开源实现与气动/气动结构优化应用有[正式论文](https://mdolab.engin.umich.edu/bibliography/Mader2020a)。这支持选择它作为研究基线，不自动认证本项目的几何、网格或求解结果。

原生 2°、Mach 0.8 的上一例用了 2508.747 秒求解，达到内部迭代预算而未取得合格收敛。另一个历史记录序列化错误已单独修复。日志里的非线性残差最低约 15758，最终回升至 26534；线性求解大部分能达到其约 0.05 的目标。没有证据称它数值爆炸，也不能单据此断言物理失速。根部四块的对称边界均严格在 z=-0.3，与原配方一致，没有依据把平面移到零。

原配方关闭了 NK，精确 ANK 切换门槛为 1e-16。参考[官方求解器说明](https://mdolab-adflow.readthedocs-hosted.com/en/latest/solvers.html)，增加明确的 `robust_rans` 数值策略：

| 设置 | 原配方 | 本次数值策略 |
|---|---|---|
| MGCycle | 3w | sg |
| 湍流子迭代 | 默认 3 | 10 |
| ANKSecondOrdSwitchTol | 默认 1e-16 | 1e-3 |
| useNKSolver / NKSwitchTol | false / 1e-8 | true / 1e-5 |
| RANS/SA、原生几何与 81 层网格 | 固定 | 不变，网格哈希验证后复用 |
| 收敛门槛、内部迭代预算 | 1e-10、3000 | 不变 |

这是有明确依据的求解策略诊断，不保证一定收敛，也不预先宣称更快。默认旧配方仍保留。14 项 CFD 合同测试通过，包含数值设置不改变物理 case hash 的检查。
