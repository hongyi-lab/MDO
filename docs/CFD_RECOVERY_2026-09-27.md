# ADflow 收敛排查与同工况重试

2026-09-27。目的：争取取得一个合格原生 CFD 算例，作为后续气动组件及 MDO 闭环的基础。不把公开教程网格、未收敛场或模型开发分数冒充最终 MDO 成绩。

## 已知事实

运行环境是固定摘要的 MDOLab 官方镜像中的真实 ADflow，非自写近似 CFD。ADflow 的开源实现与气动/气动结构优化应用有[正式论文](https://mdolab.engin.umich.edu/bibliography/Mader2020a)。这支持选择它作为研究基线，不自动认证本项目的几何、网格或求解结果。

原生 2°、Mach 0.8 的上一例用了 2508.747 秒求解，达到内部迭代预算而未取得合格收敛。另一个历史记录序列化错误已单独修复。日志里的非线性残差最低约 15758，最终回升至 26534；线性求解大部分能达到其约 0.05 的目标。没有证据称它数值爆炸，也不能单据此断言物理失速。根部四块的对称边界均严格在 z=-0.3，与原配方一致，没有依据把平面移到零。

原配方关闭了 NK，精确 ANK 切换门槛为 1e-16。参考[官方求解器说明](https://mdolab-adflow.readthedocs-hosted.com/en/latest/solvers.html)，增加明确的 `robust_rans` 数值策略：

| 设置 | 原配方 | 本次数值策略 |
|---|---|---|
| MGCycle | 3w | sg |
| 湍流子迭代 | 默认 3 | 10 |
| ANKSecondOrdSwitchTol | 默认 1e-16 | 1e-3 |
| useNKSolver / NKSwitchTol | false / 1e-8 | true / 1e-5 |
| RANS/SA、原生几何与 81 层网格 | 固定 | 不变，网格哈希验证后复用 |
| 收敛门槛、内部迭代预算 | 1e-10、3000 | 不变 |

这是有明确依据的求解策略诊断，不保证一定收敛，也不预先宣称更快。默认旧配方仍保留。14 项 CFD 合同测试通过，包含数值设置不改变物理 case hash 的检查。

## 本次运行安排与证据

1. `tutorial_control_v1`：固定 MACH-Aero wing L3 网格的小型安装/收敛对照，8 MPI ranks、1e-10、3000。明确使用 Mach 0.8、AoA 1.5°、Re=2e7、T=300K，不冒充作者原始高度工况。该网格与模型原生算例不同，不能计算配对加速比。
2. `alpha2p0_mach0p8_L81_v2_robust`：同一个原生 2° 算例，使用上表策略，8 MPI ranks。和教程控制通过同一个 compute.lock 顺序运行，不设任意墙钟上限。原网格生成成本与本次复用准备成本分开。
3. 两个已训练 Large checkpoint 各补一次修正坐标后的原生推理基准（10 次预热、30 次计时），不再训练。原生输入准备、模型加载、缓存张量预测时间分别记录。因为采样合同仍不完整，结果只作诊断。

以上是运行安排，不是成功结果。实际进度与退出状态以服务器的 `manifests/control_cfd_run.json`、`manifests/active_cfd_run.json` 和对应日志/结果为准。旧失败输出保留；没有合格收敛就不生成参考精度或成功加速倍数。不能承诺固定完成时间。

### 启动后状态

小型控制已结束：总时间 174.448 秒、求解 173.504 秒，103 次主迭代/3038 次内部迭代；相对自由流残差 9.45964e-7，未达到固定的 1e-10，退出2。该结果证明了安装能执行求解和保存完整诊断，**没有证明紧门槛收敛**；不事后把标准改到 1e-6 来称成功。原始结果和日志保存在本地 `results/server_mdo_20260927/tutorial_control`。
