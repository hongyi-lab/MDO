# 主比较：CFD 驱动 MDO 与 FM 辅助 MDO

2026-09-27 用户再次明确：**最终目的为设计优化；CFD 和 FM 都是服务 MDO 的计算手段。** 本文修正上一版将“相对于共同流动参考的预测误差”列为主目标的偏差。CL/CD/表面场拟合误差与单次求值耗时保留为组件诊断，模型适配前后结果保留为辅助对照；两者都不能替代最终设计质量和优化效率。

## 两条优化路径与共同复核

冻结同一物理设计任务、初始设计、变量范围、目标、约束、结构模型、耦合规则及验收精度。

- **CFD 驱动 MDO**：以 CFD 气动分析驱动优化，得到设计 x_CFD。
- **FM 辅助 MDO**：将气动求值替换为/优先使用 FM，需要时允许有记录的 CFD 校正或回退，得到设计 x_FM。
- **共同复核**：两个最终设计均交给相同、已核验的高精度气动—结构分析流程，独立计算目标 J_check 和约束 g_check。不能只复核 FM 设计，也不能用 FM 自己预测的低阻力作为胜出证据。

CFD 在复核中充当物理模型的一部分，不意味着必须复制 CFD 优化路径找到的设计。以 CFD 监督训练没有限制有限预算下找到的设计质量上限：FM 可能探索更多设计，并找到更好的、通过复核的可行设计。这需要实验验证。能够胜出的是给定预算下的 CFD 驱动优化流程；仅有 CFD 标签并不自动证明超越 CFD 的物理预测精度。

主图为 **已复核的最佳可行目标值 vs 累计墙钟时间**，另展示最终目标/约束和成本分项。未复核的中间模型预测须单独标明，不能把整条 FM 自报曲线当作真实优化收益。

若报告“设计误差”，须预先明确参考设计/目标，例如相对于共同最佳已复核可行设计的目标差距；不能把未知全局最优假装已知。至少包括两种比较：相同质量比时间，相同时间比质量。没有可行设计、失败和超预算全部保留。

优先固定同一外层优化器以隔离气动模块替换的影响；若优化策略不同，明确属于整套方法比较并另做归因。几何/网格准备、导数、线搜索、结构求解、耦合、回退和最终复核时间不能漏记。预留相同最终复核预算，并同时给优化时间和含复核总时间。离线适配与新增 CFD 标签成本单列并报告摊销；公共预训练成本不是本项目新增成本，但原始成本也不是零。

## 本周最小闭环的范围

保留当前组件验证，先解决真实 CFD 收敛与原生/FM接口。下一步定义一个最小气动—结构设计任务，不扩展到整机工业 MDO。

可选规模是少量展向扭转参数和翼盒厚度参数，迎角用于配平；共用同一结构模型。例如最小化翼盒质量，同时满足升力、应力、翼尖挠度、阻力上限和几何约束。具体工况、材料、变量界限、初始值及阈值须在运行前依据物理任务冻结，不看结果后修改，也不把这一示例假装已经确定并运行的实验。

闭环应为：
设计变量 → 几何 → CFD或FM气动场 → 守恒载荷传递 → 相同结构求解器 → 变形后的气动表面 → 耦合收敛 → 优化器获得目标与约束。

目前载荷传递、位移回传/网格变形、耦合收敛和总导数接口尚未全部完成。少变量首轮可以使用双方相同的无导数优化器，不把局部自动微分当作已验证的 MDO 总导数。只做单向耦合就标为单向气动—结构优化；单迎角配平、纯气动形状优化或有限候选筛选不叫完整 MDO。

本文件修正验收目标，不自动启动大规模优化、完整 CFD 数据集或昂贵网格扩展。已结束的少量 CFD 尝试保留为求解器/接口诊断，后续新计算须有明确修正依据。

## 模型训练如何面向任务

已有 CL/CD/展向载荷联合损失是起点。后续依据开发闭环失败机制，考虑目标变化和搜索方向、候选排序、约束边界与关键载荷误差。无需所有流场点同等精确，但影响目标、约束与搜索方向的误差必须暴露并处理，防止优化器利用代理误差。

优化轨迹上的新增 CFD 查询须记入数据与计算预算，并和最终评价隔离。普通场 MSE 微调仍留作消融，不改变用户指定的首要路线。

## 现有证据的定位

- 450 Train +350 Dev、Large 5 epochs 已完成。CL/CD/载荷误差改善，现有输入上的预测与积分约32ms，见 [开发结果](SERVER_MDO_PILOT_2026-09-27_RESULTS.md)。
- 尚无两套 MDO 的最终目标、可行性或总优化时间对比；目前不能报告整体 MDO 加速。
- 原生坐标、迎角、后缘及积分范围按 [接口审计](NATIVE_FM_FRAME_AUDIT.md) 对齐。两例旧原生 CFD 均未取得合格收敛结果；2度案例另有已修复的历史记录错误，见 [日志恢复诊断](CFD_ALPHA2_2026-09-27_DIAGNOSTICS.json)。后续同2°/同网格数值策略重试也已结束，46.21分钟后未通过收敛标准；原生几何/AoA修正后的两组FM推理均成功，约30ms。详见 [收敛排查](CFD_RECOVERY_2026-09-27.md)。目前无后台任务，采样合同仍未完全复现，不能从失败耗时构造成功加速。
- CFD误差与网格敏感性用于核验共同验收流程，不再是项目最终主目标。若以 CFD 作参考，定义上的零误差不能解释为其物理误差为零。

方向参考：[Wu, Mader & Martins, 2022](https://mdolab.engin.umich.edu/bibliography/Wu2022c) 比较多保真与单保真气动—结构优化的设计结果和成本，其结果不等于本项目已取得同类收益。
