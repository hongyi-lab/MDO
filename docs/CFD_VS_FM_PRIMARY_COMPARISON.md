# 主比较：CFD 与 FM 的 MDO 相关指标误差和耗时

用户于 2026-09-27 明确：主表必须是 **CFD baseline vs 我们的 FM 方法**，比较 MDO 使用的任务量误差与单次计算时间。原始 Large vs 适配 Large 属于模型改进的辅助对照，不能替代主表。本补充修正报告目标，不修改已运行的训练配置、冻结划分或已有结果。

## 共同参考与表格

对每个完全相同的机翼与物理工况，定义独立共同参考 R、正常使用的 CFD baseline B、固定权重的 FM F。两种方法都相对于 R 计算误差；R 的建立成本单独记账，不放进任一方法的单次调用时间。

| 主指标 | CFD baseline | 我们的 FM |
|---|---|---|
| 升力系数误差 | abs(CL_B − CL_R) | abs(CL_F − CL_R) |
| 阻力系数误差，drag counts | 1e4 abs(CD_B − CD_R) | 1e4 abs(CD_F − CD_R) |
| 展向升力分布误差，% | 对 R 的共同展向坐标、宽度加权相对 L2 | 同一参考、同一定义 |
| 单次调用时间 | 相同物理输入 → 合格任务量输出的实测时间 | 相同物理输入 → 任务量输出的实测时间 |

每一列同时保留任务量预测值、误差和单位。多个案例报告平均及最坏误差，并逐例配对计时；不能把350个开发工况的平均误差与另一个新机翼的一次CFD时间拼成主比较。

CFD 收敛残差不是 CL/CD 任务误差，1e-10 残差不能填写为1e-10气动力误差。未收敛结果不能充当B或R。

## 如何取得 CFD 自身的误差

- 本周可实施的数值参考：同一几何、工况、方程和湍流模型下，经迭代收敛与网格敏感性核查的更高精度解；满足外推条件时可使用外推参考。此时报告的是相对数值参考的偏差，不冒充对真实飞机的物理误差。
- 有匹配的风洞数据时才另做物理验证，并报告测量不确定度。不能将不匹配的试验几何、表面积分或工况混用。
- 若暂时只有一个合格CFD解，以它作参考只能报告“FM相对CFD的附加误差”；CFD一栏是“参考值”，不能把定义上的0解释为CFD自身没有误差。
- 两套网格的差值可报告为敏感性，不能自动称为完整CFD误差估计。进行GCI/外推前检查所需条件；不能把ADflow求解中的粗网格预迭代结果直接当独立收敛的对照。

[NASA网格收敛指南](https://www.grc.nasa.gov/www/wind/valid/tutorial/spatconv.html)区分离散误差、网格敏感性及物理真值，并建议用三档网格估计收敛阶和检查渐近区间。

先把当前独立案例算到合格、完成原生到模型接口修正，再冻结小规模网格/参考方案。服务器可用内存有限，不盲目把353万单元翻倍，不自动铺开完整CFD数据集。基线网格和收敛要求须按任务需要预先固定，不能为增加加速倍数故意把CFD算慢或挑选较差基线。

## 计时和当前证据

CFD与FM都统计从约定的物理输入到CL/CD/展向载荷的完整调用成本，列出几何/网格准备、求解或推理、积分/映射等分项。可重用网格及模型加载分开报告冷启动与后续调用；已经复用的网格不能计为本次重新生成。硬件分别明确标注CPU进程数和GPU型号，重叠负载受到控制。适配和新增CFD标签成本另列。

现有350个Dev工况已经支持FM精度和延迟评价，但**没有提供这些工况的CFD自身误差或匹配现场耗时**。第一例现场CFD未收敛；后续2度案例仍在后台。原生坐标、迎角、后缘与积分区域按 [接口审计](NATIVE_FM_FRAME_AUDIT.md) 对齐前，不解释新案例的FM误差。共同参考建立前，CFD自身误差标记“尚未测得”。

本轮任务量是MDO直接使用的CL/CD和展向气动载荷。最终油耗、机翼重量、结构约束及优化所得设计的质量，须接入相同外层问题并由共同高精度流程复核后才能比较，目前没有这些结果。
