# 原生 CFD 几何与 FM 输入坐标审计

审计日期：2026-09-27。范围：读取固定版本源码、新几何本地 bundle，以及 **v1 Train 内**的已下载几何；没有读取 Calibration/Test 场标签，没有 SSH、训练或修改正在运行的 CFD。

**结论：当前原生几何到 FM 的接口漏掉了作者 API 明确执行的坐标/迎角联合变换，且表面采样拓扑不同。旧的 raw AoA=6.71° FM 输出应标为“接口尚未对齐的诊断”，不能用于模型容量结论、精度验收或加速资格。运行中的 CFD 保留，它求解的物理算例本身并不因此失效。**

## 2. 有依据的物理等价变换

在已有负展向到正展向的镜像之后，令 `t=6.7166°`，绕原点旋转：

```text
x_ML = cos(t) * x_native - sin(t) * y_native
y_ML = sin(t) * x_native + cos(t) * y_native
z_ML = z_mirrored
AoA_ML = AoA_CFD + t
Mach_ML = Mach_CFD
```

这是几何与自由流方向共同旋转的坐标变换，不是改造机翼来降低误差。它不要求改变正在运行的 CFD 网格、几何、Mach 或原生 AoA。新生成的 FM 输入和变换身份应另存，不覆盖现有 bundle 或旧预测。

| 原生 CFD 设置 | 对应的 FM AoA | 如何解释 |
|---|---:|---|
| 本地原始示范 `AoA=2°`、Mach=0.8 | **8.7166°** | 工况数值落在已知发布任务范围；不等于已经证明几何、采样和整个流动均在分布内。 |
| 当前后台诊断 `AoA=6.71°`、Mach=0.8 | **13.4266°** | 超过 CRMpert 已知存储 AoA 上界，也超过论文 SuperWing 无安装角 AoA `[2°,12°]`；应保留为有明确工况偏移的诊断，不能包装成分布内验证。 |

CL/CD 必须用变换后的几何和迎角配套积分，参考面积、Re 长度保持原定义。Cp 是标量；切向摩擦分量的基向量要随几何一起转换。若输出全局载荷，应把向量变回 CFD 坐标系，并处理展向镜像的向量符号。

若要比较 CM，同一个物理力矩参考点也必须随坐标变换：原生 `(0.25,0,0)` 对应约 `(0.2482842014,0.0292396196,0)`。目前 CM 仅诊断，不应在旋转后继续把固定 `(0.25,0,0)` 当成相同物理点。

**发布 CRMpert 的 `geom0/origingeom` 不能再无条件重复执行这个转换。** 原生输入和发布数据输入必须有不同且明确的 frame 标识，并在转换前检查。上述证据支持修正接口，但尚未证明它解释了旧结果的全部误差，也未证明任一模型修正后一定达标。

## 3. 另一个已测得的差异：采样与后缘拓扑

比较仅使用已归入 v1 Train 的几何 0、41、82，以及本地 `results/matched_geometry_final/fm_input.npz`。没有比较新 holdout 标签或预测分数。

| 只读测量 | 发布 Train 几何 | 本地新原生 FM 输入 |
|---|---|---|
| 根部弦线，固定环索引 128 至两端平均 | 几何 0/41/82 约 +1.93/+1.96/+1.93° | −6.7166°；联合旋转后约 0° |
| 几何 0 根部环首尾点距离 | **0**，闭合环 | **0.0096 m**，保留了上/下后缘间隙 |
| 根部第 32 个环向点的归一化 x 位置 | 几何 0 约 0.8232 | 约 0.8478 |
| 展向覆盖 | 几何 0 为约 0.295833–2.958333 m | 0.3–3.0 m |

弦线角仅是可重复的几何诊断，不代表两者原本是同一个形状。使用最小 x 点定义前缘时，发布几何的根部角约为 2.1193°；上述结论不依赖具体前缘索引。

论文 §4.1.2 明确说参考采样使用固定归一化弦向位置，后缘有单元表示，并去掉一小段翼尖区域。当前本项目使用上下表面的余弦聚集弧长插值，且排除原生后缘块与翼尖块；发布 Train 几何的闭合尾端则确实不同。不能继续把“模型训练输出只覆盖 mainwing、不含后缘”当作已经核实的事实。

当前 CFD 对 `mainwing` 的分组积分，仍与**当前本项目开放环采样**的物理表面范围匹配；问题在于这个采样合同与预训练时不同。后续应先查清并复现作者的闭合环/后缘采样，再决定比较范围：

- 若 FM 积分包含后缘，应与 CFD 的相应 `mainwing + trailingedge` 范围比较，并核对截去翼尖的展向范围。
- 若仍只比较 mainwing，必须按经过审核的表面映射排除 FM 中的后缘单元。

不能只闭合最后一个点、悄悄增加后缘面积，却继续沿用旧分组真值。也不能通过测试误差挑选采样方法。该项修正需要独立记录和物理一致性检查；本审计未实施。

## 4. 未发现需要任意缩放几何的依据

作者 `simulation/single-point.py:29–30` 和 `run-adflow.py:74–75` 指定 Re=`2e7`、T=`300 K`、Re 长度=`1 m`、参考弦长=`1 m`。本地 bundle 采用同样定义，未发现仅凭这些设置即可认定的单位或 Re 长度错误。

新几何根弦约 1.2 m、半展长 3 m，与已读 Train 几何约 1.20 m、2.958 m 的量级相近；两者参考面积分别约 1.68788 和 1.71980 m²。它们是明确不同的几何和面积，不应为了贴近训练数组而任意归一化或改 Re。也不能单凭“新机翼族”名称，就把一次误差全部归因于 OOD。

## 5. 当前结果标注及后续次序

1. 保留正在运行的原生 CFD 和所有 raw FM 记录；把未转换的 FM 比较标为 `native_to_model_frame_unaligned`，不用于模型能力、容量、可靠性或 speedup 结论。
2. 新建有版本的原生到模型转换路径，验证几何/自由流共同旋转、CL/CD 坐标不变性，以及 CM 参考点处理；不改变现有已发布数据的直接推理路径。
3. 明确闭合后缘、弦向位置、展向裁切与 CFD 积分族，先消除可验证的采样/定义差异。
4. 后续以原生 CFD AoA=2°、Mach=0.8 对应模型 AoA=8.7166°作为更合理的工况对照起点；这是新建成对验证，不能替换或隐藏已运行的 6.71°诊断。
5. 接口核实后才评价 Small/Large 或适配是否有效；新合同仍需自己的 CFD 对照和校准，不继承 CRMpert 的 q。
