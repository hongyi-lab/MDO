# 独立 CFD 加速验证

本阶段先回答两个问题：模型适配能否改善未参与适配的几何上的气动预测？
校准误差界是否小到允许在预先设定容差内使用 FM？整体 MDO 暂不接入。

## A6000 上的一键精度实验

```bash
git pull --ff-only
bash scripts/bootstrap_server.sh cuda
bash scripts/run_validation.sh cuda:0
```

若服务器没有 GPU，可用 `bootstrap_server.sh cpu` 和 `run_validation.sh cpu`。
这是显式 CPU 模式；请求 CUDA 却不可用时程序报错，不会静默改成 CPU。
GPU 仅承担训练和推理；未来 ADflow 真值仍运行于 CPU/MPI。

初始配置在 `configs/cfd_validation.json`，seed=7、72 个机翼各一个公开工况。
24 个几何训练输出投影层，10 epochs、Adam、lr=1e-4、batch=1；
24 个独立几何校准；24 个独立几何最终测试。划分先生成、配置先存盘，再训练。
训练与校准数据都不能用于挑选测试结果更好的 checkpoint。

目标 CL 绝对误差容差 0.01、CD 绝对误差容差 0.0005（5 drag counts），
名义边际覆盖率 90%。这些是初期探索设置，不是工业认证标准。
每个几何只选一个工况，不能据此宣称多工况覆盖。
“未见几何”只指本次适配划分；上游预训练几何重叠没有逐一审计。

## 结果在哪里

- `report.html`：自包含 HTML，无 CDN。完整测试集的三维机翼、Cp 曲线、误差、置信度结果。
- `protocol.json` / `split.json`：事先固定的配置、模型哈希、原始样本与几何 ID。
- `adapted_checkpoint/`：可重新加载的权重、模型配置、训练来源、损失和实际训练时间。
- `pretrained/`、`adapted/`：所有预测、原始 CFD 标签、校准与测试评分。
- `summary.json`：完整结论；`live_cfd_speedup=null` 是尚未测量，不是零加速。

训练、数据/模型加载、逐次推理有独立计时。公开数据的生成成本未测量，不能视作实际成本为零。
暂不把 CPU-hours 与 GPU-hours直接相加。

## 首轮真实结果（2026-09-25）

| 24 个测试几何 | 原预训练 FM | 输出层适配 FM |
|---|---:|---:|
| CD 平均绝对误差 / drag counts | 8.7108 | 6.5387 |
| CD 最大绝对误差 / drag counts | 23.9861 | 16.8160 |
| CL 平均绝对误差 | 0.010960 | 0.010011 |
| 平均 Cp RMSE | 0.038623 | 0.037219 |
| 校准 CD 区间半宽 / counts | 17.8622 | 14.0974 |
| 观察到的 CL/CD 同时覆盖率 | 20/24 | 21/24 |
| 按固定容差允许使用 FM | 0/24 | 0/24 |

这是一项有效的负面验收结果：平均预测有所改善，但当前“小模型 + 24 标签 + 输出层微调”
还不能满足设定的替代要求。不要事后放宽容差或利用这批测试几何反复选模型以制造成功。
下一轮应先在训练部分内部设验证集来选择全参数微调/更大模型/更多工况的训练设置，
最终使用新的锁定测试集合；本轮数据和结论保留。

## 独立服务与 CFD 回退

`mdo_demo.solver.HybridAerodynamicSolver` 提供独立 `solve(query)` 接口。
输入是几何、工况、参考面积和显式固定物理条件。输出包含 Cp/Cf、CL/CD/CM、路由决定和计时。
CL/CD 校准不等价于压力场、节点载荷或梯度得到认证，CM 仍是诊断项。

校准绑定模型权重、模型配置、适配器与上游积分代码指纹、数据和划分。
超出固定 Re/T 条件、超出训练输入范围或误差界过大时，返回 `cfd_required`。
可以注入真实 CFD callback；它必须满足相同输入指纹、收敛、有限场值、相同积分定义。
未安装 callback 时不会返回伪造的 CFD 输出。当前新案例 runner 仍输出原求解器积分，
尚未完成向统一表面场的保守映射，**不能直接作为这个表面场 callback**。

从同一原生表面生成 FM 输入和 CFD 体网格，在 A6000 服务器分别运行。
这是开发案例，不是作者 CRMpert 或 STW 的精确复现。
原论文缺失完整网格输入时必须记录这一限制，不能用另一机翼的运行时间充当加速证据。

新工况需要独立建立校准集。正式通过标准还包括新鲜 CFD 对照、网格与求解收敛、
压力/摩擦力映射、载荷以及梯度验证。全部通过后才进入 MDO。
